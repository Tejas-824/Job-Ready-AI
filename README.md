AI Interview Assistant (GenAI Project)

An AI-powered full-stack application that helps users prepare for interviews by generating personalized interview questions, resume content, and improvement suggestions based on their profile and job description.

✨ Features
🔐 User Authentication (JWT-based)
🤖 AI-generated Interview Questions
📄 Resume Builder & PDF Export
📤 Resume Upload & Parsing (PDF)
💡 Personalized Suggestions for Improvement
🧠 Context-aware AI responses using structured prompts
🌐 Responsive frontend with modern UI


🛠️ Tech Stack
Backend
Node.js + Express
MongoDB + Mongoose
JWT Authentication
Google GenAI API
Multer (File Upload)
PDFKit & pdf-parse


Frontend
React (Vite)
React Router
Axios
Tailwind CSS
